**Explicación de pseudo clases y identificadores**

Las **pseudo-clases** (`:hover`, `:focus`, `:active`) modifican el aspecto de un elemento según la interacción del usuario sin usar JavaScript; por ejemplo, al pasar el cursor sobre `nav a` o `.tarjeta`, los estilos cambian para dar una respuesta visual, o al mantener presionado un enlace con `nav a:active`. Por su parte, los **identificadores** (`id`) le dan un nombre único a un elemento en HTML, como `<header id="inicio">` o `<section id="biografia">`, lo que permite dos cosas: crear navegación interna con enlaces tipo ancla como `<a href="#inicio">` para saltar a esa sección exacta, y aplicar estilos exclusivos desde CSS usando el símbolo `#`, por ejemplo en `header#inicio` o `footer#fuentes`. En conjunto, mientras los `id` como `#resumen` o `#legado` estructuran la página y organizan los saltos de lectura, las pseudo-clases aportan la interactividad visual de la interfaz.

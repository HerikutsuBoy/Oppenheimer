Las pseudo-clases permiten modificar el estilo de un elemento según su estado. En este proyecto se utilizan :hover, :focus y :active; por ejemplo, nav a:hover cambia el color y el fondo de los enlaces cuando el usuario pasa el cursor sobre ellos, mientras que .tarjeta:hover modifica la apariencia de las tarjetas. Los identificadores (id) sirven para identificar de forma única elementos HTML y facilitar la navegación entre las diferentes secciones de la página. Por ejemplo, <section id="biografia"> se relaciona con <a href="#biografia">Biografía</a>, permitiendo que al hacer clic se acceda directamente a esa sección. También se utilizan en CSS, como en header#inicio, para aplicar estilos específicamente al elemento que posee el identificador inicio.
